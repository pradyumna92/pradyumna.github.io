# Pradyumna Vissapragada — Portfolio

Public portfolio: https://pradyumna92.github.io/pradyumna.github.io/

A responsive, build-free portfolio based on the updated November 2026 resume. GitHub Pages serves `index.html`, `style.css`, and `app.js` from the main branch root. `.nojekyll` keeps publication static.

## Features

- Dark/light themes and reduced-motion support
- Career explorer, role perspectives and filterable achievement stories
- Searchable technical skills
- Illustrative pipeline and release-readiness demos
- Resume-based chat guide with email and phone links
- Optional browser speech input and synthetic speech output

## Editing

Edit page copy in `index.html`, career data and guide answers in `app.js`, and appearance in `style.css`. There is no build step. Validate JavaScript with `node --check app.js` before publishing.

The current chat is a deterministic resume guide, not generative AI and not live contact with Pradyumna. Questions are not stored or transmitted by the site. Browser speech recognition may use the browser vendor's service; visitors opt in using the microphone button. Phone and email links open the visitor's chosen application without automatically sending messages.

A generative-AI upgrade requires a separately hosted backend, server-side credentials, request limits and a visitor privacy notice. Never place an API key in these public files. No paid AI service is connected.
